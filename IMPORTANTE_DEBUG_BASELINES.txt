Fase 52 - Fix líneas amarillas/rojas de debug en Ajustes

Este ZIP fuerza a Flutter a desactivar ayudas visuales de depuración como:
- Show baselines
- Debug paint size
- Debug paint pointers
- Repaint rainbow

Aplicar desde la raíz del proyecto:

unzip -o FdezPlay_Fix_Debug_Baselines_Ajustes_Fase52.zip -d .
flutter clean
flutter pub get
flutter run

Si todavía aparecen líneas después de aplicar, cierra DevTools o desactiva manualmente:
- Show baselines
- Debug paint
- Show guidelines
